# پیش‌نمایش سایت برگرفته از فایل ZIP

> **پیش‌نمایش طراحی — نسخه نهایی سایت نیست**
>
> صفحهٔ اصلی این پیش‌نمایش از فایل ZIP ارائه‌شده توسط مالک، با همان ساختار، محتوای نمایشی و زبان بصری mint/emerald ساخته شده است. این خروجی نمونهٔ بازبینی است؛ نسخهٔ تولیدی WordPress یا تأیید محصول نیست. نصب روی پوستهٔ تولیدی فقط پس از تأیید مالک محصول مجاز است.

## بازکردن پیش‌نمایش

- صفحهٔ اصلی: `index.html`
- تنظیمات تعاملی کوروش: `theme-settings.html`
- بستهٔ آفلاین آمادهٔ بازکردن: `koorosh-design-preview.zip`؛ پس از استخراج، `index.html` را باز کنید.

برای اجرای سرور محلی از ریشهٔ مخزن:

```sh
python3 -m http.server 8000 --bind 0.0.0.0 --directory visual-preview
```

سپس `http://localhost:8000/` یا `http://localhost:8000/theme-settings.html` را باز کنید.

## منبع و بازتولید صفحهٔ اصلی

منبع بصری و محتوایی، فایل `modern-glassmorphic-plugin-website (2).zip` در `origin/main` است. SHA-256 فایل مرجع:

```text
bbc614c937375eaf903166b824adfa77b55676444917544bfcfdc5cab74d5613
```

`index.html` خروجی build تک‌فایلی Vite از همان پروژهٔ React است: hero و mockup، امکانات، پرتال‌ها، گردش‌کار، سناریوها، پشتیبان‌گیری، معماری، مقایسه، مسیر بیمار، FAQ، CTA و footer. CSS و JavaScript اصلی در همان HTML ساخته می‌شوند؛ فایل‌های فونت محلی تنها دارایی‌های جداگانهٔ صفحه‌اند.

برای بازتولید و بررسی اینکه HTML منتشرشده با همان ZIP ساخته می‌شود:

```sh
git fetch --no-tags origin main --depth=1
python3 scripts/build-zip-preview.py --check
```

برای نوشتن build تازه در پوشهٔ پیش‌نمایش:

```sh
python3 scripts/build-zip-preview.py --write
```

اسکریپت، ZIP را در پوشهٔ موقت استخراج می‌کند و به فایل‌های پوسته یا افزونه دست نمی‌زند. سازگارسازی‌های محدود و مخصوص پیش‌نمایش:

- افزودن `noindex,nofollow` و برچسب آشکار «پیش‌نمایش طراحی — نسخه نهایی سایت نیست»؛
- جایگزینی بارگیری Google Fonts با دو زیرمجموعهٔ محلی و متغیر Vazirmatn (عربی و لاتین، وزن‌های ۱۰۰ تا ۹۰۰؛ `@fontsource-variable/vazirmatn` نسخهٔ ۵٫۳٫۰) و استفاده از مسیرهای نسبی سازگار با GitHub Pages؛
- باقی‌گذاشتن ظاهر فرم CTA، اما نمایش روشن اینکه فرم نمونه هیچ داده‌ای نمی‌فرستد یا ذخیره نمی‌کند و درخواست دمو ثبت نشده است؛
- نمایش پیام کوتاه در مرورگرهای بدون JavaScript؛
- محدودکردن glowهای تزئینی به viewport و جلوگیری از سرریز ریل پرتال‌ها در موبایل.

## صفحهٔ تنظیمات

`theme-settings.html` همچنان نمونهٔ مستقل تنظیمات کوروش با همان شش بخش و تعامل قبلی است: عمومی، اطلاعات تماس، فروش و درخواست دمو، هدر و فوتر، شبکه‌های اجتماعی و وضعیت سایت. فقط توکن‌ها و تأکیدهای رنگی آن به mint/emerald و طیف آبی ZIP نزدیک شده‌اند. ورودی‌ها ذخیره نمی‌شوند و وضعیت‌ها به سرویس واقعی وصل نیستند.

## مرزهای حقیقت و انتشار

- **REAL CPMS MEDIA = NOT AVAILABLE.** فایل ZIP شامل mockup و داده‌های نمونهٔ ساخته‌شده در رابط است، نه تصویر یا رسانهٔ تأییدشده از محصول CPMS واقعی. این پیش‌نمایش، mockup را همان‌طور که در فایل مالک آمده نشان می‌دهد؛ mockup یا متن بازاریابی، اثبات قابلیت، نقش دسترسی، امنیت یا عملکرد محصول نیست.
- متن، وعده‌ها و قابلیت‌های صفحهٔ اصلی از فایل ZIP مالک آمده‌اند و به‌صورت مستقل راستی‌آزمایی نشده‌اند. آن‌ها برای بازبینی همین پیش‌نمایش‌اند، نه تأیید ادعای محصول یا مجوز انتشار تولیدی.
- فرم CTA صرفاً تعاملی و محلی است. هیچ نام، شماره، اطلاعات مطب یا توضیحی به سرور ارسال یا در مرورگر ذخیره نمی‌شود.
- هر دو سند دارای `noindex,nofollow` هستند. برچسب پیش‌نمایش نیز روی صفحه دیده می‌شود؛ چون مخزن و Pages عمومی‌اند، این موارد سایت را خصوصی نمی‌کنند.
- این پوشه به `themes/koorosh/` وابسته نیست و نباید به‌عنوان پوسته یا افزونه نصب شود.
